# Example student submissions

These fictional submissions match the default three-question rubric. Each Python file uses standard input and output so it can be exercised with Wandbox test cases.

## Input formats

- Problem 1: one JSON object with `trainingData`, `epochs`, and optional `learningRate`; output is a JSON array of predictions.
- Problem 2: one JSON object with `graph` and `start`; output contains distances and reconstructed paths.
- Problem 3: one bracket string; output is `true` or `false`.

The nine fictional students include complete solutions, slower alternatives, and progressively flawed implementations across the three problems. This gives the grading and ranking views a larger range of submissions to compare.
